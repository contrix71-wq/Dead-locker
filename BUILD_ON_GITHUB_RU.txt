СБОРКА DEAD LOCK APK ЧЕРЕЗ GITHUB ACTIONS (С ТЕЛЕФОНА)

1. Создай аккаунт на https://github.com/ (если его ещё нет).
2. Создай новый репозиторий, например dead-lock-android. Можно сделать Private.
3. Распакуй этот ZIP на телефоне.
4. Загрузи СОДЕРЖИМОЕ папки DEAD_LOCK_Android в корень репозитория (не саму папку-обёртку).
   Важно: вместе с файлами должен загрузиться скрытый каталог .github/workflows и файл build-apk.yml внутри него.
5. Открой репозиторий на GitHub → Actions → Build DEAD LOCK APK → Run workflow.
6. Дождись зелёной галочки. Открой завершённый запуск и скачай artifact DEAD-LOCK-debug-apk.
7. Распакуй скачанный artifact ZIP — внутри будет APK.

Если загрузчик GitHub на телефоне не показывает скрытые файлы/папки,
создай в репозитории папки .github/workflows вручную и добавь файл build-apk.yml
из этой поставки, скопировав его содержимое.

Это облачная сборка проекта, а не уже готовый APK. Если сборка завершится ошибкой,
открой лог Build debug APK и пришли текст ошибки.
