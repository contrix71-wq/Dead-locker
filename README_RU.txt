DEAD LOCK — Android launcher project

Что реализовано:
- PIN входа 4928.
- После правильного PIN запускается встроенное видео app/src/main/res/raw/intro.mp4 на весь экран.
- Кнопки пропуска нет; после окончания видео открывается главный экран.
- Главный экран показывает установленные приложения и позволяет запускать их.
- Меню ⋮ → «Помилование» → PIN 7610 открывает системные настройки выбора домашнего приложения.
- DEAD LOCK заявлен как HOME launcher (Android сам предлагает выбрать основной лаунчер).

Важно:
Это исходный Android-проект, а не готовый APK. В среде создания нет Android SDK и Gradle, поэтому собрать и проверить APK здесь невозможно.
Для сборки откройте папку проекта в AndroidIDE или Android Studio, дождитесь синхронизации Gradle и выполните Build APK.

Системные жесты/кнопки Android намеренно не блокируются: пользователь всегда должен иметь возможность вернуть управление устройством.
PIN-коды в этой демонстрационной версии хранятся в коде приложения и не являются защищённой аутентификацией.
